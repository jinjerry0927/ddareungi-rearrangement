## 현재 데이터 리스크

- 2,736개 중 1,023개 대여소에서 `parkingBikeTotCnt > rackTotCnt`가 관측됐다.
- `rackTotCnt`를 시뮬레이션의 절대 수용량으로 사용하지 않는다.
- 공유 거치 방식과 별도 대여소 용량 데이터의 의미를 확인한 후 용량 계약을 확정한다.
- 과거 재고 6,152,132행 중 2,516,723행이 2025년 말 명목 거치대 수를 초과했다.
- 재고 스냅샷은 `2025-10-02/09`, `2025-11-02/09`, `2025-12-02/09`가 누락됐다.
- 대여이력 표본의 반납 관련 필드에는 26행씩 결측이 있어 상태 분류가 필요하다.
- 강남구 9개 대여소는 11월 내 재고·대여·반납 활동 증거가 없어 운영 대상에서 분리했다.
- 11월 대여이력은 대여 월 기준이므로 10월 말 대여 후 11월 초 반납 건은 포함되지 않는다.
- 현재 P1은 재배치를 판단 시점에 즉시 완료해 효과의 낙관적 상한에 가깝다.
- M2 처리 데이터에는 좌표가 없어 P2에서 별도 좌표 스냅샷을 추적한다.
- P2 좌표 스냅샷은 현재 API 기준이며 2025년 운영 당시 위치와 다를 가능성이 있다.
- P2 차량은 공급 대여소에서 바로 출발해 차량의 첫 접근 이동을 계산하지 않는다.
